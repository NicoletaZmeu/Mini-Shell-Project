# Mini-Shell-Project
SimpleShell is a custom command-line shell developed in C for an Operating Systems module. The project demonstrates core OS concepts such as process creation, command execution, environment variables, input/output redirection, and background process handling. Please read the documentation in the manual directory before execution.



• **src/**
    Contains the source code for the shell, including command parsing, built-in command handling, external command execution, redirection, and     background process logic.


• **bin/**
    Stores the compiled executable file for the shell after building the project.


• **manual/**
    Contains the user manual/documentation explaining how to compile, run, and use the shell commands.



**What I Learned ?**

This project showed me that even simple terminal commands involve several low-level OS concepts. This assignment gave me a clearer understanding of process management, environment variables, file descriptors, and command execution in Linux.

I also learned the importance of writing organised code, separating logic into different folders, and creating clear documentation so that the project is easier to understand, test, and maintain.
